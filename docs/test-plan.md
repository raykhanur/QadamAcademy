# Qadam Academy — Test Plan

Күні: 27.11.2026
Нұсқа: 1.0

## 1. Тестілеу мақсаты

Веб-платформаның функционалдық талаптарға
сәйкестігін, тұрақтылығын және қауіпсіздігін тексеру.

## 2. Тестілеу ортасы

- Операциялық жүйе: macOS.
- Браузер: Safari.
- Frontend: HTML, CSS, JavaScript.
- Backend: FastAPI.
- ЖИ моделі: Qwen2.5:3b.
- ЖИ инфрақұрылымы: Ollama.
- Production: GitHub Pages.
- Local: http://127.0.0.1:8000.

## 3. Тестілеу түрлері

| Түрі | Тексеру нысаны | Әдісі |
|---|---|---|
| Functional | Негізгі функциялар | Қолмен |
| UI | Интерфейс | Қолмен |
| Integration | Frontend және FastAPI | API сұраныстары |
| Regression | Өзгерістерден кейінгі функциялар | Қайта тестілеу |
| Static Analysis | HTML және JavaScript | GitHub Actions |
| AI Evaluation | ЖИ ұсыныстары | 30 бағалау мысалы |
| Security | Қауіпсіздік тәуекелдері | STRIDE |
| UAT | Пайдаланушы сценарийлері | Қабылдау тесттері |

## 5. Ақаулардың басымдығы

| Деңгей | Сипаттама |
|---|---|
| Critical | Жүйе немесе негізгі функция жұмыс істемейді |
| High | Маңызды функция дұрыс орындалмайды |
| Medium | Жұмысқа ішінара әсер ететін ақау |
| Low | Визуалды немесе шағын ақау |

## 6. Тестілеуді аяқтау критерийлері

- Critical және High ақаулардың болмауы.
- Негізгі пайдаланушы сценарийлерінің орындалуы.
- CI тексерулерінің сәтті аяқталуы.
- ЖИ бағалау нәтижелерінің құжатталуы.
- Қауіпсіз базалық ұсыныстардың жұмыс істеуі.
- Кемінде 8 UAT сценарийінің тексерілуі.

## 7. Шектеулер

Test Cases жоспарлық сценарийлер болып табылады.
Олардың нәтижелері бөлек тіркеледі.

Тәуелсіз пайдаланушылармен UAT жүргізілмеген.
Жүктемелік тестілеу әлі орындалмаған.
Premium функциялары ағымдағы тест жоспарына кірмейді.

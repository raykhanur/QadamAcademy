## 2. Бұлттық API құнын есептеу

Салыстыру моделі: GPT-5.4 nano.
1 миллион кіріс токені: 0.20 USD.
1 миллион шығыс токені: 1.25 USD.

Дереккөз:
https://developers.openai.com/api/docs/models/gpt-5.4-nano

Тарифті тексеру күні: 26.11.2026.

Бір сұраныстың болжамды құны:

C = (128 * 0.20 + 9 * 1.25) / 1000000
C = 0.00003685 USD

## 4. GPU Break-even Point

GPU серверінің болжамды айлық құны: 150 USD.

N = 150 / 0.00003685
N = 4070556 сұраныс/ай (шамамен).

GPU серверінің өнімділігі бұл жүктемеге
жеткілікті болған жағдайда ғана есеп жарамды.

## 5. Шектеулер

Оқушылар саны мен GPU серверінің құны
болжам ретінде алынды.
Электр энергиясы мен жабдық амортизациясы
нақты өлшенген жоқ.
Бұлттық модель тестіленген жоқ.
Токен саны жергілікті модель нәтижесіне
сүйеніп болжанды.

## 6. Қорытынды

Оқу жобасы үшін Ollama қосымша API төлемін
талап етпейді. Алайда өндірістік ортада
инфрақұрылым шығындары ескерілуі қажет.

AI моделінен тиімдірек нәтиже көрсетті.

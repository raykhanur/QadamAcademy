# Qadam Academy — Business Case

Күні: 26.11.2026
Валюта: KZT

## 1. Бизнес-модель

Qadam Academy — ҰБТ-ға дайындалуға арналған
онлайн білім беру платформасы.

Ағымдағы MVP тегін жұмыс істейді.
Болашақта Freemium моделін енгізу қарастырылады.

- Basic: тегін қолжетімділік.
- Premium: айына 2500 ₸.
- Болжамды конверсия: 10%.

## 3. ROI — инвестицияның қайтарымы

Үш жылдық табыс: 5700000 ₸
Үш жылдық TCO: 2477350 ₸

Таза қаржылық нәтиже:

5700000 - 2477350 = 3222650 ₸

ROI = (Табыс - TCO) / TCO × 100%

ROI = 130.08%

## 4. Unit Economics

| Көрсеткіш | Болжамды мән |
|---|---:|
| ARPPU — ақылы клиенттің айлық табысы | 2500 ₸ |
| ARPU — барлық қолданушыға шаққандағы табыс | 250 ₸ |
| CAC — клиентті тарту құны | 1500 ₸ |
| Айнымалы шығын | 500 ₸ |
| Бір клиенттің айлық маржиналдық табысы | 2000 ₸ |

| LTV/CAC | 8 |
| CAC өтелу мерзімі | 0.75 ай |
| Маржиналдық табыс үлесі | 80% |

## 5. Операциялық залалсыздық нүктесі

Айлық тұрақты шығын: 50000 ₸
Бір ақылы клиенттің маржиналдық табысы: 2000 ₸

Break-even = 50000 / 2000 = 25

Операциялық шығындарды жабу үшін кемінде
25 ақылы жазылушы қажет.

## 6. Шектеулер

Бұл қаржылық модель болжамдық сипатқа ие.
Нақты сатылымдар және ақылы жазылымдар жоқ.
CAC, LTV және конверсия тәжірибеде өлшенбеген.
Premium функциясы ағымдағы MVP-де енгізілмеген.
ROI бастапқы TCO сценарийі бойынша есептелген.
Қосымша айнымалы шығындар, маркетинг және салықтар
ROI есебіне енгізілмеген.

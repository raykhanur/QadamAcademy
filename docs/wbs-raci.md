## 4. RACI матрицасы

R — жұмысты орындаушы.
A — нәтижеге жауапты тұлға.
C — кеңес беруші.
I — ақпарат алушы.

| Жұмыс | PM | Developer | QA | Оқытушы |
|---|---|---|---|---|
| Жобаны жоспарлау | A/R | C | I | C |
| Талаптарды анықтау | A/R | C | C | C |
| Дизайн | A | R | C | I |
| Frontend | A | R | C | I |
| Backend | A | R | C | I |
| ЖИ интеграциясы | A | R | C | I |
| Тестілеу | A | C | R | I |
| Тәуекелдерді басқару | A/R | C | C | I |
| Бюджетті есептеу | A/R | C | I | I |
| Құжаттама | A/R | C | C | I |
| Презентация | A/R | I | I | C |

## 5. Ресурстар және шектеулер

Жоба бір студентпен орындалады.
PM, Developer және QA рөлдерін бір адам атқарады.

Оқытушының C және I рөлдері ұсыныстық сипатта.
Олар нақты келісілген міндеттемелер емес.

Жұмыс көлемі Story Points арқылы бағаланады.
Нақты командалық Velocity әлі өлшенбеген.

Жаңа Premium функциялары бөлек бағаланады.

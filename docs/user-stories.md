## 3. Басымдықтарды анықтау

MoSCoW әдісі:
- Must — міндетті талап.
- Should — маңызды талап.
- Could — қосымша мүмкіндік.
- Won't — ағымдағы релизге кірмейтін талап.

## 4. Релиз шекарасы

MVP: US01–US13.

Болашақ релиз: US14–US20.

Нақты төлем жүйесі, серверлік аутентификация
және қауіпсіз дерекқор бөлек әзірленеді.

## 5. Шектеулер

User Stories ағымдағы функционал және
жоспарланған бизнес-модель негізінде құрылды.

Нақты пайдаланушылармен сұхбат жүргізілмеген.
Қабылдау критерийлері жобалық талаптар болып табылады.
Барлық критерийлер тәуелсіз UAT арқылы тексерілмеген.
ЖИ функциясы жергілікті ортада жұмыс істейді.

# ADR-001 — Жобаны басқару әдістемесін таңдау

Күні: 27.11.2026
Мәртебе: қабылданған шешімнің ретроспективті құжаттамасы.

## 1. Контекст

Qadam Academy — ҰБТ-ға дайындалуға арналған
білім беру ақпараттық жүйесі.

Жоба бір студентпен орындалады.
Талаптар әзірлеу барысында өзгеруі мүмкін.
ЖИ интеграциясы эксперименттік сипатқа ие.
Жобаның аяқталу мерзімі — 15.12.2026.

## 2. Баламаларды салыстыру

| Критерий | Waterfall | Scrum | Kanban | Scrumban |
|---|---|---|---|---|
| Өзгерістерге бейімделу | Төмен | Жоғары | Жоғары | Жоғары |

| Басқару күрделілігі | Орташа | Жоғары | Төмен | Орташа |

## 3. Қабылданған шешім

Agile қағидаларына негізделген Scrumban
элементтері бар итерациялық тәсіл таңдалды.

Scrum элементтері:
- Бір апталық спринттер.
- Sprint Planning.
- Спринт мақсаттары.
- Ретроспектива.

Kanban элементтері:
- Todo, In Progress, Done бағандары.
- Тапсырмаларды визуалды бақылау.
- Жұмыс ағынын басқару.
- Ұсынылған WIP Limit: 2.

## 4. Жобаны басқару құралдары

| Құрал | Мақсаты |
|---|---|
| GitHub Repository | Код пен құжаттарды сақтау |
| GitHub Issues | Тапсырмаларды тіркеу |
| GitHub Projects | Жұмыстарды басқару |
| Board | Тапсырмалардың мәртебесі |
| Backlog | Жұмыстардың басымдығы |
| Roadmap | Мерзімдерді жоспарлау |
| Insights | Жоба көрсеткіштерін бақылау |
| GitHub Actions | Автоматты тексеру және жариялау |

## 5. Басқару ережелері

- Тапсырмалар Story Points арқылы бағаланады.
- Басымдықтар WSJF әдісімен анықталады.
- Өзгерістер Change Request арқылы тіркеледі.
- Тәуекелдер RAID Register арқылы бақыланады.
- Код өзгерістері Git commit арқылы тіркеледі.
- Аяқталған жұмыстар тексеруден өткізіледі.

## 6. Шешімнің артықшылықтары

- Өзгерістерге жылдам бейімделу.
- Жұмыс прогресінің ашықтығы.
- Қысқа итерациялар.
- Тәуекелдерді ерте анықтау.
- Бір адамдық жобаға бейімделу.

## 7. Шектеулер

- Толық Scrum командасы жоқ.
- PM, Developer және QA рөлдерін бір студент атқарады.
- WIP Limit автоматты түрде бақыланбайды.
- Нақты Velocity үшін аяқталған спринттер қажет.
- Ретроспектива әр спринт соңында жоспарланған.

## 8. Қорытынды

Scrumban элементтері бар итерациялық тәсіл
Qadam Academy жобасының көлеміне, ресурстарына
және өзгермелі талаптарына сәйкес келеді.

Әдістеме GitHub Projects арқылы іске асырылады.

# Qadam Academy — STRIDE қауіпсіздік талдауы

Күні: 26.11.2026

## 1. Талдау объектілері

- Веб-интерфейс: HTML, CSS, JavaScript.
- Деректерді сақтау: LocalStorage.
- Backend: FastAPI.
- ЖИ моделі: Ollama, Qwen2.5:3b.
- Хостинг: GitHub Pages.
- CI/CD: GitHub Actions.

## 3. Деректер ағыны

1. Пайдаланушы веб-интерфейспен әрекеттеседі.
2. Тест нәтижелері LocalStorage ішінде сақталады.
3. ЖИ функциясына тест идентификаторлары мен сандық нәтижелер жіберіледі.
4. FastAPI сұранысты жергілікті Ollama моделіне жібереді.
5. Интерфейс базалық алгоритмнің ұсынысына басымдық береді.

| Деректерді қорғау | LocalStorage қауіпсіз дерекқорды алмастырмайды |
| Аудит журналдары | Енгізілмеген |
| Құпиялылық саясаты | Дайындау қажет |
| Кәмелетке толмағандардың деректерін қорғау | Қосымша құқықтық бағалау қажет |

## 5. Қорытынды

Qadam Academy оқу мақсатындағы MVP болып табылады.
ЖИ функциясы жергілікті ортада жұмыс істейді.
Толық серверлік аутентификация, RBAC және аудит
журналдары енгізілмеген.

Өндірістік ортаға шығару алдында қауіпсіздік
тестілеуін және дербес деректерді қорғау
талаптарына сәйкестікті бағалау қажет.

Қауіп деңгейлері сараптамалық бағалау негізінде
анықталды. Бұл талдау қауіпсіздік аудитін немесе
ену тестілеуін алмастырмайды.

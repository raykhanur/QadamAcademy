# Сәтсіз IT жобасын талдау — Healthcare.gov

## 1. Жоба туралы ақпарат

Жоба: Healthcare.gov.
Ел: АҚШ.
Іске қосылған күні: 01.10.2013.
Мақсаты: медициналық сақтандыруды онлайн таңдау
және рәсімдеу платформасын құру.

## 2. Негізгі мәселелер

- Платформаның қолжетімділік мәселелері.
- Өнімділіктің жеткіліксіздігі.
- Бағдарламалық қателер.
- Жүйенің толық дайын болмауы.
- Жобалық шығындардың өсуі.

FFM жүйесіне бөлінген қаржылық міндеттемелер
56 млн доллардан 209 млн доллардан астам
мөлшерге дейін өсті.

## 5. Қорытынды

Healthcare.gov жобасының бастапқы іске қосылуы
жобалық басқару, сапаны бақылау және талаптарды
басқарудың маңыздылығын көрсетті.

Кейін жүйені жақсарту бойынша шаралар қабылданды.
Сондықтан бұл толықтай тоқтатылған жоба емес,
бастапқы релизі сәтсіз болған IT жоба.

Qadam Academy үшін негізгі басқарушылық шешім —
функционалды кезең-кезеңімен енгізу және
тексерілмеген мүмкіндіктерді өндіріске шығармау.

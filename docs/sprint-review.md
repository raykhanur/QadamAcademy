Velocity формуласы:
Спринт ішінде аяқталған Story Points қосындысы.

Throughput формуласы:
Белгілі бір кезеңде аяқталған тапсырмалар саны.

Cycle Time формуласы:
Done уақыты - In Progress басталу уақыты.

Lead Time формуласы:
Done уақыты - тапсырманың тіркелу уақыты.

## 6. Sprint Retrospective

### Start — бастау

- Тапсырмалардың нақты орындалу уақытын тіркеу.
- WIP Limit шектеуін сақтау.
- Әр релизден кейін тест нәтижелерін сақтау.

### Stop — тоқтату

- Бір уақытта бірнеше ірі тапсырманы орындау.
- Тексерілмеген ЖИ нәтижесіне сену.
- Құжаттаманы соңғы күнге қалдыру.

### Continue — жалғастыру

- GitHub Projects арқылы басқару.
- CI/CD автоматтандыру.
- Тәуекелдерді бақылау.
- ЖИ сапасын Evals арқылы бағалау.
- WSJF арқылы басымдықтарды анықтау.

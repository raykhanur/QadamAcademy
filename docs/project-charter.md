# Qadam Academy — Жоба жарғысы (Project Charter)

Күні: 27.11.2026
Нұсқа: 1.0

## 1. Жоба туралы ақпарат

Жоба атауы: Qadam Academy.
Жоба түрі: білім беру ақпараттық жүйесі.
Мақсатты аудитория: ҰБТ-ға дайындалатын оқушылар.
Жоба менеджері: студент.
Басталу мерзімі: 25.11.2026.
Жоспарлық аяқталу мерзімі: 15.12.2026.

## 2. Жобаның негіздемесі

ҰБТ-ға дайындық курстарының жоғары бағасы
оқушылардың білім алу мүмкіндігін шектеуі мүмкін.

Qadam Academy оқушыларға қолжетімді бағамен
өздігінен дайындалуға, тест тапсыруға және
оқу нәтижелерін бақылауға мүмкіндік береді.

## 3. Жобаның мақсаты

15.12.2026 дейін қазақ тіліндегі ҰБТ-ға дайындық
платформасының MVP нұсқасын әзірлеу, жариялау,
тестілеу және жобалық құжаттаманы дайындау.

## 4. SMART мақсаттар

- 10 пән бойынша оқу материалдарын ұсыну.
- 100 сабақ пен 440 тест сұрағын енгізу.
- 44 тест және жеке кабинет әзірлеу.
- GitHub Pages арқылы платформаны жариялау.
- ЖИ функциясын кемінде 30 мысалмен бағалау.
- 15 зертханалық жұмыстың портфолиосын дайындау.

## 5. Жоба шекарасы (Scope)

### Ағымдағы MVP

- Басты бет және пәндер каталогы.
- Оқу материалдары.
- Тіркелу және жергілікті аккаунт.
- Тестілеу жүйесі.
- Жеке кабинет және оқу статистикасы.
- Базалық ұсыныстар алгоритмі.
- Жергілікті ЖИ прототипі.
- CI/CD және GitHub Projects.

### Болашақ релиз

- Freemium бизнес-моделі.
- Әр пәннің алғашқы 5 сабағы тегін.
- Premium: айына 19 990 ₸.
- Таңдалған 5 пәнге толық қолжетімділік.
- ЖИ негізіндегі жеке есептер.
- Жеке дайындық жоспары.
- Сынақ ҰБТ және таймер.
- Серверлік аутентификация.
- Дерекқор және төлем жүйесі.

## 6. Технологиялық стек

- Frontend: HTML, CSS, JavaScript.
- Backend: Python, FastAPI.
- Деректерді сақтау: LocalStorage.
- ЖИ: Ollama, Qwen2.5:3b.
- Хостинг: GitHub Pages.
- CI/CD: GitHub Actions.
- Жобаны басқару: GitHub Projects.

## 8. Жобаның негізгі тәуекелдері

- Жобаның кешігуі.
- ЖИ ұсыныстарының қателері.
- Деректердің жоғалуы.
- Қауіпсіздік шектеулері.
- Оқу материалдарының сапасы.
- Болашақ жазылымға сұраныстың төмен болуы.

Толық талдау RAID Register құжатында берілген.

## 9. Жобаның табыстылық критерийлері

- Веб-платформа қолжетімді болуы.
- Негізгі функциялардың тестілеуден өтуі.
- CI/CD жүйесінің жұмыс істеуі.
- ЖИ бағалау нәтижелерінің құжатталуы.
- Қате ЖИ ұсыныстарының пайдаланушыға
  негізгі ұсыныс ретінде берілмеуі.
- Жобалық портфолионың дайын болуы.
